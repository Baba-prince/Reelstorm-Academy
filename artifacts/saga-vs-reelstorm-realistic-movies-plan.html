REELSTORM CINEMA

New phase design: merge Saga’s showrunner clarity with ReelStorm’s factory assets — without making users walk 18 developing angles.

Captain’s call: Do not delete BOT Director as a dead-end. Absorb it into Showrunner (the conductor). Ship a new primary product surface — Cinema Mode — with exactly four studios you named (Cast · World · Voice · Cut). Everything else becomes Factory Mode (power tools / distribution), not the default path to realistic AI movies.

1 · Decision: new phase, not more rooms

Problem
Current product feels “almost complete” in every direction at once — Debate, YT-OS, Clone, Camera, Wizard, World Builder, Studio Set, Merge, Archive… Users cannot find the movie path.
Wrong move
Add Saga as a 19th room beside BOT Director. Complexity doubles; realism still fails.
Right move
Phase: Cinema OS — one spine, four studios, Saga-class locks. Keep existing rooms as Advanced Factory behind a toggle / producers menu.
BOT Director
Retire as primary UI · Keep as engine — its 7 stages (Idea→Cast→World→Beats→Voice→Render→Ship) become the invisible Showrunner pipeline that drives the four studios. Route /wizard → /cinema.

3 · The four studios (only UX users need for movies)

1 · Avatar Studio

CAST · CHARACTER LOCK

  • Create / import lead + supporting cast
  • Multi-angle plates (front / 3Q / side)
  • Lock face → Character Bible ID
  • Outfit slots by story-day
  • Absorbs: Model Center Avatar, Soul ID, artist plates

2 · Scene Studio

WORLD · STUDIO SET

  • Generate / lock locations
  • Multi-angle room plates (real stills, not SVG)
  • Imagery DNA shared with board + shoot
  • Absorbs: Studio Set, World Builder, Camera angle prompts (as helpers)

3 · Voice Studio

CLONE · BIND · SYNC

  • Clone or pick voice per character
  • Bind voiceId ↔ Character Bible
  • Lip / body sync on dialogue shots
  • Absorbs: Sound Studio, translate lipsync hooks

4 · Video Studio

EDITOR · ASSEMBLE · SHIP

  • Storyboard → approve → shoot
  • Timeline: trim, order, cliffhanger cut
  • Music / SFX beds + export master
  • Absorbs: Storyboard, Generate, Archive, Merge, Studio chat

6 · Why absorb BOT Director (not delete)

Keep the brain

  • Idea → Cast → World → Beats → Voice → Render → Ship already matches Saga’s order
  • Blueprint JSON + project feed already exist
  • Deleting it throws away orchestration you already paid for

Kill the brand as “another room”

  • Users should not choose Wizard or Studio Set or Saga
  • Showrunner = one button: “Make this season”
  • Studios open only when the spine needs input / approval
